### Career Readiness Score
- Definition：A composite 0–100 score produced by the Master Career Agent that summarizes how prepared a candidate is for their target role, derived from resume quality, GitHub evidence strength, job-match fit, and skill coverage.
- Aliases：readiness score、score

### Verified Skills
- Definition：Skills that appear both in the uploaded resume AND are corroborated by actual GitHub repository activity; only these skills are treated as demonstrated rather than claimed.
- Aliases：verified

### Unverified / Claimed Skills
- Definition：Skills listed on the resume but not backed by observable GitHub evidence; flagged separately so candidates know which competencies lack proof.
- Aliases：unverified_skills、claimed skills

### Master Career Agent
- Definition：The orchestrator agent that consumes outputs from the Resume Analysis, GitHub Evidence, Job Matching, and Skill Gap agents and synthesizes them into the final career profile, roadmap, and hiring-readiness summary.
- Aliases：Master Agent、orchestrator

### 30-day learning roadmap
- Definition：A week-by-week plan generated by the Master Agent listing focus areas, tasks, and expected outcomes to close identified skill gaps within one month.
- Aliases：roadmap_30_days、learning roadmap

### Hiring readiness summary
- Definition：A narrative verdict produced by the Master Agent stating whether the candidate is ready to apply for their target role and what remains to be done.
- Aliases：hiring_readiness_summary
